Функции
- Веб-интерфейс (Next.js).
- API для работы с данными (NestJS).

Как запустить
1. Backend
   - Перейти в папку backend:
     ```
     cd backend
     ```
   - Установить зависимости и запустить:
     ```
     npm install
     npm run start:dev
     ```
   - Или:
     ```
     yarn
     yarn dev
     ```

2. Frontend
   - Перейти в папку frontend:
     ```
     cd frontend
     ```
   - Установить зависимости и запустить:
     ```
     npm install
     npm run dev
     ```
   - Или:
     ```
     yarn
     yarn dev
     ```

Запуск в разработке
1. Сначала запустите backend, затем frontend.
2. При необходимости настройте переменные окружения в соответствующих папках (`.env`).

Сущности системы
Новость (News)
ID новости - генерируется автоматически

Заголовок новости - обязательное поле

Содержимое новости - обязательное поле

Изображение - необязательное поле

Дата публикации - генерируется автоматически через Entity

Комментарий (Comment)
ID комментария - генерируется автоматически

ID новости - обязательное поле (связь с существующей новостью)

Автор - необязательное поле (по умолчанию "Anonymous")

Комментарий - обязательное поле

Backend API (NestJS)
Эндпоинты для новостей
GET /news
Получение списка всех новостей

Возвращает: массив объектов со всеми полями, кроме "Содержимое новости"

Поля в ответе: ID, Заголовок, Изображение, Дата публикации

POST /news
Создание новой новости

Проверяет: обязательность полей (валидация на уровне модели)

Поддерживает: загрузку файла изображения

GET /news/:id
Получение одной новости по ID

Возвращает: полный объект новости со всеми полями, включая содержимое

DELETE /news/:id
Удаление новости по ID

Каскадное удаление: при удалении новости удаляются все связанные комментарии

Эндпоинты для комментариев
GET /comments
Получение списка всех комментариев

Фильтрация: при передаче ?news_id=ID возвращает только комментарии указанной новости

POST /comments
Создание нового комментария

Проверяет:

Наличие ID новости в запросе

Существование указанной новости

DELETE /comments/:id
Удаление одного комментария по ID

Frontend (React + Redux Toolkit)
Страницы
Главная страница - список всех новостей (краткий просмотр)

Страница просмотра поста - полный просмотр одной новости

Отображает все поля новости

Выводит список всех комментариев к данной новости

Возможность добавления нового комментария

Возможность удаления комментариев

Особенности реализации
Автоматическое указание ID новости: при создании комментария на странице новости

State management: весь стейт (кроме двусторонней привязки данных) хранится в Redux

Альтернатива: можно использовать Zustand вместо Redux Toolkit

Технические требования
База данных
СУБД: MySQL

ORM: TypeORM

Генерация даты: через defaultValue в Entity

Функции
- Веб-интерфейс (Next.js).
- API для работы с данными (NestJS).

Как запустить
1. Backend
   - Перейти в папку backend:
     ```
     cd backend
     ```
   - Установить зависимости и запустить:
     ```
     npm install
     npm run start:dev
     ```
   - Или:
     ```
     yarn
     yarn dev
     ```

2. Frontend
   - Перейти в папку frontend:
     ```
     cd frontend
     ```
   - Установить зависимости и запустить:
     ```
     npm install
     npm run dev
     ```
   - Или:
     ```
     yarn
     yarn dev
     ```

Запуск в разработке
1. Сначала запустите backend, затем frontend.
2. При необходимости настройте переменные окружения в соответствующих папках (`.env`).
